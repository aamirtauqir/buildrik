## B. Prioritized UX Issue List

Grouped under the founder's three concerns. Severity: **Critical** = blocks core task / data loss · **High** = confusion in common flows · **Medium** = friction · **Low** = polish. No Critical found — the core build flow works; the pain is a *cluster of High issues* that together read as "unprofessional / incoherent."

| D-1 | Inspector body is dense + tight | Medium | Density | reach cards + tabs + breakpoint row + accordions + 2-col controls (Size/Weight/Line height/Letter spacing) in 280px → cramped, hard to scan → same root as G-3 (too many systems, one column). |

### Root-cause synthesis (read this if nothing else)
Most High findings trace to **one** missing thing: a **shared "panel/toolbar shell" + grouping system**. Each surface (topbar, rail, panels, inspector) was built on its own, so grouping, naming, and density each drifted. That's why it "feels AI-designed" — not because any one screen is wrong, but because **nothing shares a skeleton.** Fixing that root cause (a `PanelShell` every panel uses + a canonical element-name source + grouped topbar/rail) resolves G-1, G-2, C-1, C-2, C-3, D-1 at once — the prior audits found the same leverage (one root-cause fix clears 3–7 symptoms).

## C. Recommended Architecture

Five moves. The first is the root-cause fix; the rest fall out of it. Each shows before → after.

### Move 0 — The shared skeleton: one `PanelShell` (fixes C-3, D-2, half of the "AI feel")
Every left panel renders through ONE component with three fixed slots, so Insert / Pages / Styles / Settings become one family instead of four mini-apps:
```
PanelShell
├── Header     title + (optional) help/close          ← same on every panel
├── Nav slot   tabs OR segment OR nothing             ← one place panels may differ
└── Body       grouped sections (labeled groups)      ← always grouped, never flat
```
Rule: a panel may only vary its **Nav slot** and **Body content** — never its header style, padding, or group pattern. Settings already does this; make it the template.

### Move 1 — Topbar: 3 zones, dividers between (fixes G-1, G-4, D-3)
```
BEFORE:  ‹Exit   ↶↷⟲      Site›Home▾      [🖥▭▯▢]   ●Saved·13m  ✨Ask AI  +Invite
         (7 things floating, only device toggles grouped)

AFTER:   ‹ Exit │ ↶ ↷ ⟲   │   Agency›Client›Site›Home▾   [🖥 ▭ ▯ ▢]   │   ●Saved   │   ✨Ask AI   ↗Share
         └ leave + history ┘   └──── where am I + view ────┘        └status┘   └─ actions ─┘
```
- Three labeled zones with thin `│` dividers: **Navigate** (Exit + edit-history) · **Context** (breadcrumb + device) · **Status + Actions** (Saved is status; Ask AI + Share are actions — separated from status by a divider).
- Rename "+ Invite" → "Share" and demote to last (collaboration is secondary on a solo draft — fixes the earlier B-finding too).

### Move 2 — Left rail: group by intent (fixes G-2)
```
BEFORE:        AFTER:
 ▦             ▦  (brand / home)
 +  Insert     ──────────────
 ▢  Pages      +  Insert     ┐ CREATE
 🎨 Styles     ▢  Pages      ┘ + CONTENT
 ⚙  Settings   ──────────────
               🎨 Styles     ┐ DESIGN
               ⚙  Settings   ┘ + SET UP
```
- One thin divider splits "make the page" (Insert, Pages) from "make it yours / configure" (Styles, Settings). The divider alone gives the rail an implied order — no labels needed at rest, labels on hover.

### Move 3 — Inspector: collapse 6 levels → 2 (fixes G-3, D-1)
```
BEFORE (6 levels):                 AFTER (2 levels):
 div / h2                           Editing: Heading        ← one name (Move 4)
 YOU ARE EDITING / this heading     [This item ▾]  📱1200+  ← reach + breakpoint = inline chips
 [This item][All like this][Whole]  ─────────────────────
 Look | Layout | Effects            ▾ Content
 Desktop·1200+   +state             ▾ Size & spacing
 ▾ Text  ▾ Size  …                  ▾ Color & text
                                    ▾ Effects   ▾ States
```
- Delete the **Look/Layout/Effects tab row** and the **breakpoint nav row**. Reach becomes a small dropdown chip; breakpoint becomes a chip next to it. The body is ONE job-grouped accordion (Content → Size & spacing → Color & text → Effects → States) — users scroll, not navigate. (This is the prototype's intended inspector + the prior P-10 fix.)

### Move 4 — One canonical element name (fixes C-1, C-2)
- A single `displayName(element)` source used by the floating toolbar, both breadcrumbs, and the inspector. A heading is **"Heading"** everywhere — never "h2", "H Heading", or "this heading".
- Keep **one** breadcrumb (the canvas bottom crumb, it's contextual). The footer drops its breadcrumb and keeps only connection + zoom. Footer also drops `v2.14.0` (dev noise).

### Before → after, in one line
> **Before:** four panels that look like four apps, a scattered topbar, a 6-level inspector, an element with four names.
> **After:** one panel skeleton, a topbar in three labeled zones, a 2-level inspector, one name per element. Same features — one body.

```

        — finally, the tokens —                             ▸ All tokens & presets   (advanced, collapsed)
                                                            ▸ Shared theme ↗
```

### What the eye lands on now (hierarchy)
1. **Canvas** (the page) — biggest, center, calm.
2. **Inspector "Editing: X" + the one group you opened** — your current job.
3. **Breadcrumb** — where you are.
4. Everything else (rail icons, status, zoom) — quiet until needed.
