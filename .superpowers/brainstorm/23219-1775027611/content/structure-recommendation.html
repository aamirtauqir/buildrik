Recommended App Structure

Monorepo layout — Dashboard & Editor as parallel modules, shared backend

Constraint: Next.js requires app/ at root

Next.js ka app/ directory root ya src/ mein hona chahiye — move nahi ho sakta dashboard/app/ mein. Is liye recommended structure:

Recommended Structure
buildrik/ ├── app/ ← Next.js routes (must stay at root) │ ├── auth/ ← Auth pages │ ├── dashboard/ ← Dashboard pages │ └── api/ ← API routes (tRPC) │ ├── dashboard/ ← Dashboard module │ ├── components/ ← All dashboard UI components │ └── emails/ ← Email templates │ ├── editor/ ← Editor module (UNTOUCHED) │ ├── src/ ← Editor source code │ ├── demo/ ← Editor dev server │ └── vite.config.ts ← Editor build config │ ├── server/ ← Shared backend (dono use karein) │ ├── trpc/ │ │ ├── routers/ ← All tRPC endpoints │ │ └── trpc.ts ← Context & base procedures │ ├── services/ ← Business logic │ ├── auth.ts ← NextAuth init │ └── auth.config.ts ← Auth providers │ ├── lib/ ← Shared utilities │ ├── prisma.ts ← DB singleton │ ├── utils.ts ← Shared helpers │ ├── trpc/client.tsx ← tRPC client │ └── validations/ ← Zod schemas │ ├── prisma/ ← Shared DB schema ├── types/ ← Shared TypeScript types │ ├── middleware.ts ← Next.js edge middleware ├── next.config.mjs ← Next.js config ├── package.json └── tsconfig.json

Kya move hoga?

From To Why
/components/ /dashboard/components/ Dashboard UI grouped under dashboard module
/emails/ /dashboard/emails/ Email templates are dashboard-specific
/app/ /app/ (stays) Next.js constraint — must be at root
/server/ /server/ (stays) Shared backend — dono modules use karein
/lib/ /lib/ (stays) Shared utilities — dono ke liye
/editor/ /editor/ (stays) Untouched — no rewrite
