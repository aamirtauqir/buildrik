1. PRODUCT IDENTITY

Buildrick is a visual website builder that turns design into production-ready code.
Category: no-code / visual web platform.

2. AUDIENCE PERSONA

Age: 25–40
Technical sophistication: advanced — designers who understand structure and code, plus developers who want to skip repetitive front-end boilerplate.
Psychographic trait: craft-driven but execution-fatigued — they care deeply about quality, but they do not want slow handoffs or messy implementation.

3. BRAND FEELING

Precise. Confident. Premium.

4. COLOR PALETTE

Use the same palette, but with more restraint and hierarchy:

Void: #060608

Surface: #0A0A0A, #111111

Paper: #FFFFFF

Accent: #4F46E5

Light mode surface: #FAFAFA

Functional-only secondary colors:

Emerald: #10B981

Amber: #F59E0B

Violet: #8B5CF6

Apple-style use means:

one dominant accent: indigo

secondary colors only for status, system states, or data signals

no rainbow feel on the homepage

Headline:

8. KEY DIFFERENTIATOR

A visual builder with production standards built in.
Every layout becomes clean, semantic HTML. Design tokens propagate globally. The result is faster execution, less cleanup, and no designer-to-developer handoff gap.

Tagline / framing:
Structure over Surface. Logic over Templates.

9. ANIMATION INTENSITY

4 — Rich, but restrained.

Use:

GSAP ScrollTrigger

staggered reveals

Framer Motion springs

scroll progress feedback

But the feeling should be:

calm

controlled

cinematic in polish, not in spectacle

So technically it is still 4, but visually it should feel more refined than flashy.

10. TECH STACK

React + Tailwind + GSAP + Framer Motion
Fonts: Inter Tight for display, JetBrains Mono for labels/badges
Component system: fully bespoke, no external library

11. CONTENT ASSETS

No photography is needed.
The visual system should rely on code-drawn product mockups:

editor chrome

layout canvas

CMS tables

AI assistant panel

token controls

semantic structure views

Aesthetic direction: dark, interface-forward, abstract, premium, product-led.
The mockups should feel like the hero object—not just screenshots, but polished product sculptures.
