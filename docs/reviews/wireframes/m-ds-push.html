WIREFRAME · M-DS-PUSH · CHANGE CONTRACT
M-ds-push — the shared theme push contract. The missing surface (audit finding A · ownership-map footnote 3 · the wedge's biggest footgun). When an agency changes the workspace shared theme, it can hit many live client sites at once. This is NOT per-element styling and NOT a 4th reach — it's a workspace action with its own review + apply flow: marker → diff → per-site override resolution → confirmed push → per-site result.
