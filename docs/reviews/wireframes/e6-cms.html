Dynamic page template → design it in the editor ↗
Build the post layout once; bind elements to fields (heading→Title, image→Cover, body→Body). Every entry renders through it. Per-entry SEO (title/description) comes from the fields — the M-seo pattern level, not hand-written 200×.
Job-to-be-done: "publish many similar pages without rebuilding each." Collections + a bound template + a field-driven SEO pattern do exactly that. A Content editor can add/edit entries (content); changing the fields or template is Designer/Admin (M-roles). Entries publish with the site.
