3 · Why is this disabled? — density vs permission, never confused the rule that kills the support tickets codex predicted
Hidden by DENSITY (Simple)
All CSS · CSS classeshidden in Simple
"Turn on full controls to see this." A one-click reveal — you're allowed to use it, it's just folded away. Reversible preference.
Blocked by ROLE (Client)
Redirects · Custom codeyour role can't edit
"Your role (Client) can't edit this — ask an admin." A permission boundary, not a hidden control. Flipping density never unlocks it.
The rule (from M-roles): every disabled/hidden control names its cause — density (reversible, "turn on full controls") or role (permission, "ask an admin"). Never an unexplained grey button. This single discipline removes the "missing feature" and "why is this disabled?" ticket classes.
