WIREFRAME · LOW FIDELITY · USABILITY FIX (A)
Editor ↔ Dashboard boundary map · fixes the "same thing in two places, no clear home" complaint · one rule: Editor = make the page (content + page-scoped config) · Dashboard = run the business (between/after design sessions) · every dup → one home + a mirror, never 404 deep-link from the other side so muscle memory survives

✎ EDITOR authors

make the page — open while designing

Anything that changes what's on the page or is scoped to one page/element. You're in here with a canvas in front of you.

  • Page content, layout, components
  • Per-page SEO & per-page <head>
  • Brand: fonts, colors, favicon, default OG
  • Design tokens / styles
  • Media used in the page
  • Quick "publish this draft"

⚙ DASHBOARD operates

run the business — open between sessions

Anything that operates the live site or the account — edge/publishing infra, money, people, traffic. No canvas needed.

  • Domains, DNS, SSL
  • Site-wide SEO defaults & redirects
  • Site-wide custom code / security headers
  • Analytics, form submissions inbox
  • Team / access / share links
  • Billing, plan, workspace settings

Dashboard: URL slug, published-site password, danger-zone (rename/transfer/delete) → 14-site-settings. One field, one owner — no double-edit.
The "mirror, never 404" contract: when a feature's home moves to the other side, the original side keeps a labeled deep-link in the same spot — showing the effective value read-only where useful (e.g. domain status, SEO default). The control is gone; the scent and the jump stay. This is why agency users' muscle memory survives the move (§11.5). Implemented today on 53-settings as the four "↗ Dashboard" ops links.
Why a scope split, not deletion: we don't remove power — we give each setting exactly one editable home chosen by the rule (page-scope → editor, site/operations → dashboard). The other side mirrors. This closes the v1 "same setting in 3 places" problem without taking any capability away. See the de-clutter fix (B) for how the editor surface itself goes calm: fix-editor-declutter.html.
