WIREFRAME · M-SEO · MANY-PAGE MODEL
M-seo — how SEO works when a site has many pages. The fix to a real gap: "SEO → Site + Pages drawer" doesn't scale to 50 pages. SEO is mostly per-page (every page needs its own title + description for Google). The model = 3 inheritance levels + one overview table. Content SEO (titles/desc/OG, per-page) is editor-owned — authored with the content; technical SEO (canonical · index · sitemap) lives in the dashboard.

The rule: a page's SEO = its override if set, else the site default (or the collection pattern for dynamic pages). The page drawer always shows the effective value with an "inherited" vs "custom" tag, so you know what Google will see without guessing.

Why this is the answer to "many pages": you never hunt page-by-page. The overview table shows every page's effective SEO, flags gaps (missing/duplicate titles & descriptions, accidental noindex), and lets you edit inline or jump to the page. Sort/filter by "has issues." This is one screen, not 50 drawers.
3 · Where it lives + where AI helps
Homes (per ownership map) content: editor · technical: dashboard
Site defaults → Editor › Site › SEO. Per-page → Pages drawer › SEO (override). Overview table → Editor › Pages › "SEO view". Pattern → the collection's settings. Dashboard shows a read-only SEO health mirror ("3 issues · Edit in editor ↗") — never a second editor.
AI does the boring part Operate
The exact job AI should do for a non-technical user across many pages:
"Generate SEO for all pages missing a description" → fills the 1 gap, drafts from page content, you review + apply
Per the audit's AI redesign: AI's "Operate" job = generate page SEO / alt-text / fix duplicates. Scope label + affected count + preview before apply.
Net: SEO scales because it's inherit-by-default + override-where-it-matters + one overview to find gaps + AI to fill the rest. A 5-page site sets defaults once and is done; a 50-page site lives in the overview table; a 500-post blog uses one pattern. All three are the same content-SEO model, editor-owned (technical SEO = dashboard). Founder-call #1 (content SEO owner = Editor) still holds — this just shows it works at scale.
