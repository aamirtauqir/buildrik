1

Group the rail into 4 verbs, fold the rest under “More”

11 flat icons become Make · Page · Design · Ship (Add/AI/Media · Pages/Layers · Design · Publish). Power tabs — Templates, Components, History, Settings — live under a More ▾ reveal, still one click, still ⌘K-reachable. Labels under the verbs, not opaque 2-letter glyphs. See the grouped rail on editor-spine-wireframe.

2

Progressive disclosure in the inspector — 3 groups, not 16 flat sections

The 3 Style/Element/Effects tabs + 16 sections collapse into Common (Style, Text, Spacing — open by default), Layout & box (collapsed), and Advanced (Effects, Interactions, CSS classes, All-CSS — collapsed, labeled “reveal”). Nothing is removed; the long scroll becomes a short, named stack. Grounded in 59-inspector.

3

Calm defaults — “Simple” opens few, “Advanced” reveals all (one toggle, persistent)

The density toggle already exists. Make Simple the calm default: rail = the 4 verbs, inspector = Common only, no CSS box. Flip to Advanced once and it sticks for that user — Pro/agency gets the full surface revealed, never re-hidden. Same engine underneath; this is purely what shows first. Code box / All-CSS only appears in Advanced.

4

Pin the scope banner — answer “what am I editing?” before any control

The single biggest “can’t find / scared to touch” driver is not knowing whether a change hits one element or 31. Keep the You are editing banner pinned at the inspector top (element name + shared-class count), with the propagation guard on class-bound edits. Calm ≠ hiding consequences — it means making the consequence the first thing you see.

5

One way in for power users — ⌘K to any control, no hunting the rail

Grouping + folding means a Pro never loses speed: ⌘K jumps straight to any tab, section, or setting by name (“redirects”, “all CSS”, “components”). The calm surface is for scanning; the command palette is for muscle memory. So we can fold aggressively without slowing the expert. See 71-command-palette.

Pro-first, not dumbed-down: agencies said “good features, but not user-friendly” — the problem is everything shouting at once, not missing depth. Every move here is reveal-or-group, zero removal. The de-clutter pairs with the boundary fix: moving site-ops to the Dashboard (fix-boundary) also empties ~6 screens out of the editor’s Settings tab, so the editor surface gets quieter on both axes.

What lands where: the Settings tab shrinks to page/brand config only (brand, fonts, language, per-page <head>) — see 53-settings. Design tokens stay their own calm tab (ds1-design-system). Add stays sections-first for beginners (52-add). Result: a Pro editor that’s quiet to look at and deep to reach.
