PROTOTYPE · M-EDITOR · the canonical editor
M-editor — the canonical editor. One calm surface. The rail is 4 structural tools (Insert · Pages · Styles · Site) — never more. Density (how much depth shows) is a per-user setting seeded by role, set in account settings — not a switch in the editor, so the chrome never changes under you or your client. AI is a separate assistant (top-right ✨) that can edit the whole design, not just insert blocks. Page structure = the ⌗ icon in the bottom status bar (opens a floating panel) + click-on-canvas. Never a fixed left panel the client must keep scanning.
