Why this beats the 5-rung ladder
fix-styling-model — 5 rungs (cosmetic)
  • User must understand element vs class vs component vs preset vs token to change a button.
  • Needed a whole explainer screen + a decision table to be usable.
  • "Preset" and "Token" are engine words a no-code user has no model for.
  • Ordering the rungs didn't remove a concept — still five.
3 reaches — concepts removed, not reordered
  • One question, three plain answers. No engine vocabulary.
  • Class-vs-component is decided by the editor from what's selected.
  • Preset/token hide behind "the brand" — same power, no jargon.
  • Three words a beginner already owns: this, all like it, the brand.
