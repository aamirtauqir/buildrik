↳ Branch — save conflict (rare, step 2). If the site changed in another tab/device, we never silently overwrite: show what's different, default to keep both (save mine as a copy), overwrite only behind a type-to-confirm. Save conflict ↗
↳ Branch — undo & restore. In-session undo/redo is the editor topbar (↺ History). Every publish is a restorable version on the dashboard — roll back a live site in one click (with a confirm). Versions ↗
↳ Branch — who can publish. A Designer/Admin publishes directly. A Content editor with approval ON sees "Send for review" instead — the agency approves before it goes live. Roles ↗ · Approval ↗
One promise: never lose work. Autosave, conflict-keeps-both, approval gate, and restorable versions are the four safety nets across the whole path — no step can silently destroy a client's site.
