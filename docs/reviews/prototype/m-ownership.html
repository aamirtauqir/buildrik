M-ownership — one home per concept (suggested map). Codex's #1 fix: before any cut or merge, decide who owns each contested concept. This is my recommended call for every one, with the mirror rule. Ratify or flip. Rows shaded + flagged decided ✓ are genuine product decisions where my pick could reasonably go the other way — those are the ones to confirm first.
The rule: every concept has exactly ONE authoring home (where you WRITE it). It may appear elsewhere only as a read-only mirror with an Edit in [home] ↗ link — never a second editable copy. Page-level things get one override home (the page drawer). Mirror ≠ duplicate (codex): 53-settings's "mirror, never 404" pattern is the thing to spread, not delete.
Editor = make the thing (Page/Section/Element + content config) Dashboard = run the business (Workspace/Client/Site ops) Workspace = agency-shared (cross-client) founder call (my pick, flip if you disagree)
