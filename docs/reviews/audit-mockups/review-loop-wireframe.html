Every state (frame 03–05, the client view)

The happy path is ~10%. The new client-review surface needs all of these or it'll feel broken — the exact complaint that started this.

Empty

No comments yet — "Click anywhere on the page to leave feedback."

Loading

Fetching the site + existing comments. Skeleton, not blank.

Error

Comment failed to save → inline retry, never a silent drop.

Password

Wrong password → clear message; right → remembered via cookie.

Expired / revoked

expiresAt past or isActive=false → "This link is no longer available."

Already approved

Verdict already given → read-only banner, no double-submit.

Submitting verdict

Approve/Request-changes pending → button busy, disabled.

Success

Confirmation: "Thanks — the team has been notified." (closes the loop)
