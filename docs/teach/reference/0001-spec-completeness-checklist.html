B · Arithmetic — hamesha jodo

Dimension likhna kaafi nahi. Har layout ka jod milna chahiye. Ye teen check har baar chalao:

VERTICAL     sab bands ka jod  =  viewport height
             56 + 36 + BAND + 32 = 900   →  BAND = 776  ✓

HORIZONTAL   chrome + canvas   =  viewport width
             60 + 320 + CANVAS + 300 = 1440  →  CANVAS = 760  ✓

MONOTONIC    viewport chhoti karo → koi region BADA nahi hona chahiye
             1440 → canvas 760 ;  1439 → canvas 1079   ✗ TOOT GAYA
Ye galti asli hai

Shell wireframe v1 ne likha band = 768. Jod: 56 + 40 + 36 + 768 + 32 = 932, viewport 900. Footer hi drop ho gaya tha. Har number "reasonable" lag raha tha — jod nahi mil raha tha.

D · Frame pehle — ye order bacha leta hai

  1. Viewport chuno (design + minimum). Arithmetic yahin se shuru.
  2. Shell banao asli size pe — har region labelled.
  3. Reusable frame banao (drawer, modal, panel) — ek baar.
  4. Cargo bharo — 6 panels ab ek hi frame ke bachche hain.
  5. States har screen ke liye.
  6. Copy + stress aakhir mein.

Ulta karoge to har screen alag se design hogi aur aapas mein match nahi karegi.
