- Integration impact: All work on the site stops persisting, silently except for the misleading banner.
- Probable root cause: slug uniqueness is enforced only in the page-settings slug field.
- Dependencies: L3-013.

- Labels: BROKEN FUNCTIONALITY · CODE ONLY ISSUE
- Category: Broken existing feature
- Type: Functional
- Severity: Critical
- Problem: Selection survives a page switch. Smart placement in the Add panel walks up from the stale selection, so the new element is inserted into the **other** page's tree. The visible page stays empty.

- Figma status: not checked (behaviour).
- Code status: `packages/editor/src/editor/shell/hooks/useBlockInsertion.ts:77-125` (uses `selection.getSelectedIds()` with no active-page check); `PageManager.setActivePage` `:225-239` never clears selection (phase-1 P2-6, now proven harmful).
