## Found on the way
1. **False-positive "Link URL looks malformed" on every root-relative link.** `checkLink` in `packages/shared/content/contentIssues.ts` runs `new URL(href)` with no base, so `/about`, `/services` and `/` are all flagged. That puts false warnings in both the Issues panel ("Home › See services") and the server "Links" pre-check (S1: "2 links are broken" when every link is valid).
2. **Once any CMS binding exists on a site, every editor open dirties the page and autosaves.** On S1 with a binding, `sites.saveProject` fires on plain load (owner 200). For a **VIEWER** the same load save returns 403, and the viewer sees the red "Couldn't save Verify Site One · Home … Retry save" banner with the Home tab marked unsaved (`found-v3-viewer-ubf5-load.png`, `X8-v3-2-activity.png`). With the binding removed, neither role saves on load. The binding save also stores the bound heading's static `content` as `""`.
3. **Publishing is impossible from the editor UI in simulation mode.** `runPrePublishChecks` always marks "Vercel connected" as fail when no connection exists, so "Publish now" is disabled. The server's `startPublish`, meanwhile, skips that check under `PUBLISH_ALLOW_SIMULATION=true`. The local publish loop the flag exists for cannot be reached from the editor.
4. **A-17: the collection's template page publishes its placeholders.** `about.html` shipped `<h1>{title}</h1>` as a normal page next to the generated `blog/verify-post-1/index.html`.
5. **The generated dynamic page has an empty `<title></title>`** when the collection has no SEO title pattern. It should fall back to something.
6. **B-2 copy.** When only the status poll fails, the panel says "Publish failed… The previous live version is unchanged". That is an unverified claim: the job may have succeeded server-side, and here it did (the job reached COMPLETED).
7. **A dev-overlay console error on the "Save as component" path:** "Removing a style property during rerender (borderColor) when a conflicting property is set (border)…" (React style warning).
8. **Seed drift from other sessions.** New sites "Verify Site One (Copy)" and "(Copy) (Copy)" appeared in the workspace during this pass; they were not created here.
