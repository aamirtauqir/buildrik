## Found on the way

1. **Opening the editor on a site with a CMS binding triggers an unrequested save that rewrites the bound element's stored content.** On O the stored `text-2.content` went from "A seeded site…" to "Nested" (save right after binding), then to `""` after a plain reopen plus save.
   - For a **viewer** the same auto-save fires with no interaction at all and returns **403**. A red banner then reads "Couldn't save Verify Site One (Copy) · Home — Your changes are still here…", and the Home tab gets a dirty dot (`DV3-x-viewer-idle-O.png`).
   - Control: the same idle 22 s as viewer on C, which has no bindings, gives 0 saves and 0 banner (`DV3-x-viewer-idle-C.png`).
   - This is also why the share draft in row 2 renders stale or empty values.
2. **The Webhooks form copy is stale.** It says "form.submit — ready, but nothing sends it yet (form capture is unbuilt)". Form capture is built and working (row 1c).
3. **A workspace-less user gets a generic "Couldn't load your dashboard / Something went wrong on our end"** instead of a create/join-workspace state. Seen for `unverified@`, which the seed gave no membership; a real signup creates one.
4. **Duplicating a site copies a stale `data-form-block-id` attribute.** It points at S1's seed FormBlock id and ships in the published HTML (`<form data-buildrick-id="form-12" … data-form-block-id="cmui3swhl000uji7wzuyjubf5-home-contact-form">`). Wiring keys on `data-buildrick-id`, so there is no functional effect. It does leak another site's row id into public markup.
5. **The editor Preview drops the form's input and Submit button.** "Get in touch" renders with nothing under it (`DV3-3-preview.png`), while the canvas shows Email + Submit. I did not investigate further.
6. **Harness traps:**
   - The Next dev-tools "N" button sometimes docks over the editor's Site menu and intercepts clicks. Removing `nextjs-portal` from the DOM fixes it.
   - The canvas elements' attribute is spelled `data-buildrick-id` (with "ck").
   - Hover-revealed row buttons need a hover first.
7. **Cross-agent activity was visible during the run, not caused by me:**
   - S1 was published at 08:36 and 08:44, which added `(S1, form-12)`.
   - S2 was renamed to "S2 Renamed A4v3" and had text elements added, then renamed back.
