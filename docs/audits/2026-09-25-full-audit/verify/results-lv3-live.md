## Found on the way
1. **[HIGH] A single click on a link element in the editor canvas navigates the whole editor away.** On S2 I clicked `link-28` (`href="/services"`) with one ordinary Playwright click to select it. `page.url()` went from `/edit/S2` to `http://192.168.100.5:3100/services`, a dashboard 404 page. No prompt appeared, and the editor was gone. I reproduced it twice (`LV3-4-probe.png`). Any root-relative link on the canvas does this. It was not investigated further.
2. **Switching page tabs with no edit sends a `saveProject`.** Clicking the About tab on S1 as OWNER sends one save (200, content unchanged). It happens with and without CMS bindings, so it is not the Lv3 #2 regression, but it is an unrequested write. Viewers are unaffected (read-only never autosaves).
3. **The share payload ships all `projectCmsBindings`**, including bindings on hidden pages: collection ids and field slugs. It ships no entry data.
4. **The Delete key on a selected Layers row does nothing,** even for an unlocked element (image-27: 1 → 1). This is a harness note for 4b; it may be by design.
5. A **"Locked · Unlock" toast** stays in the toast stack after a lock action and was still listed seconds later.
