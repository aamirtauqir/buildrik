## Found on the way

- **Always-present design-annotation overlay widget** injected into every editor page in this dev build (bottom-left "N" avatar; opening it shows "Output Detail / Standard / React Components / Hide Until Restart / Marker Color / Clear on copy/send / Block page interactions / Manage MCP & Webhooks / MCP Connection / Webhooks / Auto-Send"). It intercepted Playwright's pointer-event dispatch on at least one occasion (`brand-tokens-first-load-text` tooltip blocking a click) and its hidden panel text leaked into several `body.innerText()` captures, which is why some of the "notes" fields above look like they include unrelated UI copy. This looks like a third-party dev/annotation tool bundled into the local build rather than a product feature — worth checking it's dev-only and stripped from prod bundles.
- **Cross-agent DB contamination**: S1's Home page heading was repeatedly overwritten mid-session by what appears to be another concurrent verifier session (`area editor-a`/`C-4`/`C-9`-shaped edits: "WINNER-B", "tabA-edit1", "edited-editor-role fromTabA"), and the site was auto-published at least once during this pass ("Published — site is live" banner appearing unprompted). Not a product bug, but it means any other area's results touching S1 in the same time window should be cross-checked for interference.
- Brand panel's per-token detail card computes and displays a live contrast ratio ("5.9:1 contrast on Background") the moment a finding is dismissed — a nice, well-built affordance, not a bug.
