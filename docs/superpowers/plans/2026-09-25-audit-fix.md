## Global Constraints

- Root `CLAUDE.md` and `packages/editor/CLAUDE.md` rules apply. In particular:
  - Page → tRPC → Router → Service → Prisma, with no skipped layers.
  - Shared Zod schemas live in `packages/shared/schemas/`.
  - No `any`, no `../../` imports, no dead code, no pass-through wrappers.
  - Chrome is built from `@/editor/chrome-ui` only, with `tw:` utilities and `--bk-*` tokens, and no raw `<button>/<input>` (Gate 24).
  - Accent `#1A56DB`; purple/violet/indigo banned.
- Every new `process.env.X` read gets a row in the root `CLAUDE.md` env table in the same commit.
- **Never stage `AquibraStudio.tsx` edits made in the founder's tree.** All work happens in the lane worktrees, never in `/Users/shahg/Desktop/pencil/buildrik`.
- **No `git stash`** (CLAUDE.md). No push, no deploy, no prod DB. Prod steps (crontab, TimeZone, XFF) are written as runbooks only.
- A test that pins the old behaviour is changed **in the same commit** as the fix. The ledger `pinning_tests` lists them.
- Each fix is its own commit: `fix(<area>): <ID> — <what>`. Commit bodies end with the Co-Authored-By trailer.
- The pre-push hook runs `verify:ds`. The lane gate before merge is `npx vitest run` (root and editor) plus `npx tsc --noEmit` (editor and dashboard) plus `pnpm run verify:ds`.
