overturned, which is the exact failure the V2 page exists to prevent. They are now in a
`## REFUTED` section at the foot, marked `DO-NOT-IMPLEMENT`.

is still named `The 55 Criticals` while rendering 46. The number to trust is the one
`scratchpad_audit/mod/criticals.json` carries, because that is the payload the board draws.

Status vocabulary: `PENDING` · `IMPLEMENTED` (needs a read-back) · `ALREADY-CORRECT`
(needs the read-back that proves it) · `NOT-APPLICABLE` (needs a reason) · `BLOCKED`.
`VERIFIED` is set only by a QA agent that re-read the board itself.
