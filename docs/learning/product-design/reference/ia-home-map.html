Reference · Home-map worksheet · IA SSOT

Every feature. One home. One verdict.

The deliverable of Lesson 13. The whole feature set, regrouped by the user's job (not the backend module), each with a single home (Editor / Dashboard) and a verdict. This is the SSOT every builder cites for "where does X go?" — seeded from the real inventory + backend-map.

The scope test (decides every home): "Is this about one site's content, or about many sites / the business?"
Inside one site → EDITOR  ·  Across sites / the business → DASHBOARD

Verdicts — keep as-is · merge a duplicate into one home · fix a wired-but-broken backend · hide until the backend is real (constitution #3) · cut entirely.

Hide until the backend is real (#3)

AI "create site" · Stock photos/videos · Real-time collab (6 P1 bugs) · Billing upgrade CTA · Localization · Data export (no processor). None of these earn nav space today — design the slot, gate the feature.

Completeness test

Before you call the home-map done, three checks: (1) Does every feature have exactly one home? (2) Does every group name a user job, not a backend module? (3) Are top-level items ~5–6, not 17? If yes to all three, the structure now matches how the user thinks — and "where does this go?" has a fixed answer.
