After the pass — the sequence

  1. Sort the Ghost + Half rows by user pain (severity × frequency).
  2. Wireframe each gap — handoff + all states.
  3. Write the redesign plan from those wireframes.
  4. Pressure-test it: plan-design-review + plan-ceo-review.
  5. Build via the 5-rung ladder; re-test the job.
