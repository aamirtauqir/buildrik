Start with the journeys, not this list. The top-level structure is the 5 job journeys in wireflows.html — the sequences the user moves through (Make a page · On-brand · Content · Sign-off · Ship). This page is the appendix those flows reference: each flow step points to a §N here for the panel's detail.
⚠️ Tags reconciled to shipped code — 2026-06-28. A code audit cross-checked every ✅/🟡/🔵 against packages/editor/src. Where a tag was false or inverted it now reads ⚠️ with the real state. Live-rail truth: Insert · Pages · Styles · Site (Media / Templates / Components fold under Insert) — not the drawn Insert · Media · Pages · Design.
