The editor as journeys, not a list of panels.

Job-to-be-done first: each screen earns its place inside a journey the user moves through, left to right. Panels (Insert, Inspector, Pages…) are the blocks a flow uses — not the top-level spine.

The journey is the unit. Each screen earns its place inside a flow the user moves through — not as a standalone panel. The 41 per-surface specs live in the surface appendix; they're the blocks these journeys pass through, not the top-level structure. Read the flows first; drop into a §N when you need a panel's detail.

User: agency builder, empty page. Done when: a real section is on the canvas, styled, saved. The job pulls toward one thing: get content onto an empty canvas fast — so every step's hero is "the next move," and the chrome stays quiet until the user needs it.

J2 Make it on-brand
