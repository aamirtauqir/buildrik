How to read the gap

Every surface has a spec in the surface appendix (§0–§38) — the 41 panels drawn low-fi. These are the blocks; the user journeys that string them together live in wireflows.html. The 7 ◐ "partial" surfaces (Insert · Pages · Media · Interactions · Animations · Design/Brand · States) have a basic screen but want deeper state-sets — that's polish inside each flow's build, not a coverage gap.

Sequence (L12): (1) yeh map confirm karo — kya aap ki saari functionality theek hai? (2) phir har to-draw surface ko wireframe banao (5-step recipe, L17), to-draw → 0. (3) phir plan-design-review. (4) phir build (5-rung).

Honesty note: status icons 2026-06-23/24 code-audit se hain (kuch 🟡/🔵 ab ✅ ho chuke — version-history, components, stock, my-templates server-models shipped). Surface count ≈; exact number redesign ke dauran settle hoga. Yeh map living hai — surface draw hoti jaaye, drawn column update.
