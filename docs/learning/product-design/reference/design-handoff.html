For the designer / Figma — what "fix" means

These wireframes are grey-box low-fi (structure + copy, no styling). The job is to apply Buildrik's design system and make them hi-fi, on-brand, consistent. Per DESIGN.md (the SSOT — do not deviate without sign-off):

  • One accent: cobalt #2D6DFF only. Purple / violet / indigo are banned.
  • Type: General Sans (display), Inter Tight or Geist (body/UI), Geist Mono (data). No Arial / Helvetica / Roboto / default stacks.
  • Spacing: 4px base, compact density. Editor chrome inspector rows ≥32px.
  • Motion: minimal. No spring physics, no scroll choreography.
  • Theme: canonical light theme, desktop-only (dark direction was dropped 2026-04-18).
  • No AI-slop: no decorative gradients-for-the-sake-of, no fake dashboards, no emoji-as-icon, no glassmorphism. See the anti-slop list in DESIGN.md.
  • Priority: polish the ◆ first-slice screens first (the agency wedge: Clients → Sites → Brand → DS-push → Review → Publish). The rest is P1/P2 — see ia-tree.html for the full build order.
  • States are not optional: each screen ships its empty / loading / error / success set (the States section above is the catalogue).
