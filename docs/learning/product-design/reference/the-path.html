Where you are, and the road to pro.

Two halves. The craft (done — you can make a thing well) and the pro frontier (the habits that aim the craft at the truth instead of your guesses). Both run on one engine: the constitution + the five-step loop.

done The craft — make it well

Audit & name (L1) → rate (L2) → place by principle (L3, L5) → hand off to a builder (L4) → write the rules down (L6) → design every state (L7) → build & verify without breaking (L8). Proven on the real topbar.

now The pro frontier — aim it at the user

1. User-first — every problem starts from who · what-job · where-stuck, not the UI. 2. Research — watch ~5 real users attempt one real task; let their stumbles drive the work. 3. Measure — write "better = ___" before, check it after. See L9.

next Apply it to Buildrik — the improvement loop

Pick the core job: "an agency operator publishes a client's site." ① Watch 5 people attempt it (silently). ② Turn every stumble into a rated finding (constitution + severity). ③ Fix the worst via the five-step loop. ④ Re-test the same task — did 5/5 now succeed? ⑤ Move to the next surface. Order by user pain, not by what annoys you.

later Compound it — taste, breadth, community

Grow the constitution as new cases appear (principles stay few, patterns grow). Study one great product a week (how does Linear / Figma / Webflow handle this surface?). Post a screen + your findings to a community (RESOURCES) and let strangers find what you missed. Taste is pattern-recognition built from reps.

The one-line version

Craft makes it well. The user tells you what "well" means. Measurement proves you got there. AI does the typing — you bring the taste and the "no."
