Reference · Figma-review prompt · MCP scan recipe

The AI finds only what you tell it to look for.

Figma MCP sees structure, not intent — it can list frames, nodes, fonts, sizes, overlaps. It cannot judge "this is off-brand" or "this is a dead-end" unless you hand it the rule. So your list of issues = your list of criteria. "Review my file" → vague mush. Name the lens + the criteria + the output shape → real issues with node-ids.

Rule 0 — read-only, Pro server, one skill first. Tell it: use the plugin_figma_figma server (saqib/Pro, no cap — not the capped account), load /figma-use before any scan, and don't edit — findAll scan only. A review that mutates the file is not a review.

The 4 slots — fill them, paste it

ACCESS — which file + "Pro server, load /figma-use, read-only findAll, don't edit." LENS — which kind of review (pick one or stack): hygiene · brand · coverage. CRITERIA — the actual rules to check against (your brand tokens, your jobs/flows, "no empty frames"). THIS is what turns the flashlight into a finding. OUTPUT — the shape: a table (issue · node-id · severity · fix), then screenshot the worst frames so you can eyeball them.

Worked prompt — your actual file

ACCESS — SCAN my Figma file RmtnWGlZX9Z3idP6f5vmLq for issues. Use the Pro Figma server (plugin_figma_figma). Load /figma-use first. Read-only — findAll over top-level frames, don't edit anything. LENS — three passes: hygiene, brand, coverage. CRITERIA — hygiene: flag frames with 0 children, nodes with width or height = 0, overlapping or off-canvas frames, duplicates. brand: list every font family + every fill colour; flag anything NOT in {General Sans, Inter, Geist, Geist Mono} and any accent that isn't cobalt #2D6DFF (purple/violet/indigo banned). coverage: each of my 6 jobs (J1 run-business · J2 start-site · J3 build · J4 on-brand · J5 sign-off · J6 ship) must have a frame; every wireflow must end on a real live/done state — no blank, TODO, or dead-end. OUTPUT — one table: issue · node-id · severity (P1 blocks / P2 should-fix / P3 polish) · fix. Then get_screenshot the 3 worst frames so I can eyeball them. Re-scan once to confirm counts before reporting.
The honest ceiling. An MCP scan is a coherence + hygiene review — it proves the file is tidy and on-brand and complete. It can never prove the design is right for users. A spotless Figma scan ≠ a validated product; that still needs real agencies (correctness). Don't let a green scan feel like a green light.

Eye + structure — pair the two tools

findAll reads the tree (counts, names, fonts, sizes) — the structure. It can't see "ugly" or "low contrast." For the eye, add get_screenshot on the suspect frames — it renders the frame to an image you actually look at. A complete review = scan (structure) + screenshot (eye). Ask for both.
