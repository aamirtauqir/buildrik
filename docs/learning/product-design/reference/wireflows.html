★ The agency wedge — capture once, push to all, sign off, ship the first slice · the differentiator

User: agency operator managing many client sites. Done when: one brand change reaches every selected client site, each client signs off, all ship — from one place. This is the cross-job SPINE, not one of the 6 jobs: it threads J1/J2 (clients · sites) → J4 (master brand) → the wedge push (§36) → J5 (sign-off queue) → J6 (ship).
