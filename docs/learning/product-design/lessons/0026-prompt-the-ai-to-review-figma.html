Lesson 26 · ~5 minutes

Make the AI review your Figma file — by handing it the rules.

Aap ne poocha: "Figma file MCP se access karni hai — par usko review kaise karaoon, issues kaise nikloon, kya prompt likhoon?" Ek line ka jawab: AI sirf wohi dhoondta jo tu usse dhoondne ko kehta. MCP file ki structure dekhta (frames, nodes, fonts, sizes) — par "yeh off-brand hai" ya "yeh dead-end hai" woh tab tak nahi jaanta jab tak tu rule na de. Issue-list = criteria-list.

"Review my file" kyun bekaar hai

✗ Vague

"review my Figma file RmtnW… and find issues"

AI ke paas koi kasoti nahi. "Issue" ka matlab kya? Off-brand? Khaali frame? Missing flow? Bina rule ke woh ya to kuch nahi nikalta, ya random cheezein bolta.

✓ Aimed

"scan for empty frames, fonts not in {General Sans, Inter, Geist}, and any flow that dead-ends — report node-id + fix"

Ab har pass ki ek kasoti hai. Jo rule diya, wohi issue mila. Repeatable.

Yeh prompt-engineering ka pehla usool hai: clear + explicit criteria do — model tera dimaag nahi padh sakta.[1] Review prompt mein criteria = woh cheez jo flashlight ko finding banati.

Prompt ke 4 slot

ACCESSkaun si file · Pro server · read-only
→
LENSkis tarah ka review
→
CRITERIAasli rule — yahi finding banata
→
OUTPUTtable: issue·node·sev·fix

Teen lens (ek ya teeno stack kar): Hygiene (khaali frame, zero-size node, overlap — pure structure, AI khud jaanta), Brand (har font + colour list karo, allow-list ke bahar wale flag karo), Coverage (har job/flow ka frame hai? har flow real state pe khatam hota?). Koi issue aasmaan se nahi tapka — har ek ek diye-gaye rule ka output tha. Maine font allow-list na di hoti, font-sprawl kabhi na pakra jaata.

Honest chhat (ceiling). MCP scan sirf coherence + hygiene saabit karta — file saaf, on-brand, poori hai. Yeh kabhi saabit nahi karta ke design users ke liye sahi hai. Spotless scan ≠ validated product — woh abhi bhi asli agencies maangta. Green scan ko green-light mat samajh.

Ek aur jod: aankh + structure

findAll tree padhta (counts, naam, font, size) — structure. "Ugly" ya "low contrast" nahi dekh sakta. Uske liye get_screenshot jodo — woh frame ko image bana deta jo tu khud aankh se dekhta. Poora review = scan (structure) + screenshot (aankh). Dono maango.
