2 · Pro vs slop = job-first, na ke module-first

Yeh poore arc ka capstone hai (L18, LR-0018). Coverage "complete" feel hoti hai par job-first nahi hoti. Tell: screen ke upar Job: likhna usse job-first nahi banata — agar screen abhi bhi controls ki list hai.

✗ Module-first (slop)

Top-level = Insert · Media · Pages · Design. Screen = controls ki list. Job sirf ek label jo control inventory ke oopar baitha hai. User ke dimaag se match nahi.

✓ Job-first (pro)

Top-level = kaam (build · brand · sign-off · ship). Screen = ek journey ka step. Job ne screen ko shape diya, sirf annotate nahi kiya. "Yeh kahan jaata hai?" ka fixed jawab.

Jahan phisla — wahan fix. Yehi "professional" finish hai, bina code.
