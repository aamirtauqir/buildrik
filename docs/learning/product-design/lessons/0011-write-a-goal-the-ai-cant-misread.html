Direct the AI: a goal it can't misread, and can't fake "done".

You asked the practical question — to start Phase 0, how do I do it, what do I add, what prompt do I write? This is the vibcoder skill made real: a build-prompt is the handoff plus a verify clause, written so the AI builds the right thing and can't claim it's done without proving it. Two ideas make the difference.

Two things amateurs leave out of an AI prompt
1. "Check the code first" — so the AI doesn't reinvent what already exists.
2. "Verify before you claim done" — so "done" means proven, not asserted.

Idea 1 — make it CHECK before it builds

The most common way an AI "builds the wrong thing" isn't bad code — it's building something that already existed, or missing something already there. Half of bad output is a wrong assumption. So the first line of any build-prompt: "read the current code and confirm what exists; don't assume."

Phase 0 is the perfect example. Collaboration already had a feature flag (FEATURE_COLLAB, off by default). A naive prompt — "add a flag to hide collab" — would send the AI to build a second flag and miss the real job: auditing that every collab UI surface respects the flag that already exists. "Check first" turns a wrong build into the right one.

Idea 2 — what YOU add is information, not code

You don't usually hand the AI new tools or code up front. You hand it three things only you have:

You supplyBecause the AI can't know…
The why (the user pain)…what to optimise for. "Users can't tell success from error" → it builds feedback, not decoration.
The acceptance (your bar)…when you'd call it done. State the checklist.
The constraints…the unwritten rules: "don't ship collab," "cobalt only," "don't touch the engine."

The shape — five slots + a verify line

CONTEXT (why + check-first) · WHAT · WHERE · DON'T-BREAK · DONE · VERIFY ("climb all 5 rungs; don't claim done until verified"). The full fill-in-the-blanks version, with the Phase-0 prompt written out, is the build-prompt template — keep it open and reuse it for every phase.

Starting it "as a goal"

Paste the prompt, or use /goal with a one-line completion condition: "Phase 0 complete — collab + broken UI hidden behind flags, tsc + tests green, browser-verified." The goal's stop-hook won't let the work end until that condition holds — which forces the verify step you'd otherwise be tempted to skip. The goal is your "don't let me declare victory early" guardrail.
