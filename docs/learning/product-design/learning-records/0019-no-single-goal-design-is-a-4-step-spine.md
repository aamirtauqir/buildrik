# 0019 — There is no single "goal" to run: design is a 4-step spine, and the founder already walked it

**Date:** 2026-06-29
**Status:** active

## What happened
Three days after the wireframe arc closed (LR-0018), the founder came back confused: *"existing app ki IA, user-flow aur wireframe professional banani hai, bina code — kaun sa goal run karoon?"* The question assumes a single command/skill that produces the redesign. It doesn't exist — and the founder had, across the whole arc, already produced all four design artifacts (ia-home-map = jobs, ia-tree = IA, wireflows = flows, editor-wireframe = wireframe). The confusion wasn't a missing step; it was **lost through-line** — the arc sprawled across coverage maps, autoplan, codex, demand gates, and the simple shape underneath got buried. Taught Lesson 21: the design lane is one spine — **Jobs → IA → Flows → Wireframe** — with a "you are here" marking all four as done, so the real next move is a job-first shape-check, not a rebuild.

## The teachable thing
**"What goal do I run?" is the wrong shape of question — it wants a button; design is a sequence.** L19 already taught "pipeline not a button," but it framed the whole 8-stage / 3-lane (Design·Validate·Build) machine. The founder scoped *today* to design-only, no code — so the right teaching wasn't the whole pipeline again, it was to **collapse the design lane to its four rungs and show the order is the content.** Each rung is the *fruit* of the one above: jobs feed the IA grouping, the IA feeds the journeys, the journeys decide which screens get wireframed. Skip or reorder a rung and you get the LR-0018 failure (screens first, jobs labelled on top = module-shaped slop).

**When a learner has done the work but feels lost, the gap is orientation, not output.** This is LR-0015 again ("you're not stuck, you're in the gap"). The instinct is to teach a new technique or run a new build. Wrong move — they don't need more artifacts, they need a one-glance map that says "design = these 4 steps, you've done all 4, here's the single check left." The tangible win was *clarity*, delivered as a "you are here" table, not new drawing.

**The professional finish on an existing app is a shape-check, not a rebuild.** Because all four exist, "make it professional" reduces to: read the four artifacts top-to-bottom against the *same* 6-job list and flag where any step drifted module-shaped (the known drift: IA index `Insert·Media·Pages·Design` = backend modules, LR-0018). Job-first end-to-end is the acid test that separates pro from slop. No code, no rebuild — just verify the spine holds one job vocabulary from top to bottom.
