# SITE.md — Buildrik Editor Redesign

## 1. Vision
Redesign the Buildrik visual web editor with a premium, utilitarian-dark aesthetic. The editor is a professional-grade tool for building websites visually — it has 29 engine managers, 10 sidebar panels, 13 inspector sections, 12 canvas overlays, and 30+ keyboard shortcuts. The redesign upgrades visuals without losing any functionality.

## 2. Design Direction
- Premium dark theme inspired by Linear and Vercel
- Utilitarian, developer-focused aesthetic
- Stitch has full creative freedom on colors, typography, spacing, and visual language
- Must feel like a $200/mo SaaS product, not a toy
