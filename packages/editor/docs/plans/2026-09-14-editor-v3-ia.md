## 3. Conventions (unchanged from Clone 2)

- Shell 1440×900: Topbar / Middle band [Rail 60 · Drawer (pinned) 280 · Canvas 800 · Inspector 300] / Footer.
- Names: `CURRENT DESIGN ·` live · `STATE ·` host of a reference panel · `STATES · …` launcher · REFERENCE / ARCHIVE / PROPOSED / LIBRARY / FRAGMENT non-live · VERIFY / START HERE / CHANGELOG / AUDIT docs.
- Reactions: `{trigger:{type:'ON_CLICK'}, actions:[{type:'NODE', destinationId, navigation, transition:null, resetScrollPosition:false, resetVideoPosition:false, resetInteractiveComponents:false}]}`.
- **Never** start an action list with CLOSE when a NODE action follows (aborts in playback when no overlay is open). SWAP only from an overlay. NAVIGATE alone dismisses overlays.
