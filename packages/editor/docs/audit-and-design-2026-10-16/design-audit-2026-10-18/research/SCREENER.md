# Screener

Use as a short form or a 5-minute call. Don't mention Buildrick features. Q = qualify, X = disqualify, T = tag for quota.

| # | Question | Answers → logic |
|---|---|---|
| 1 | Which best describes your work? | Freelance / independent designer → T solo · Designer at an agency or studio → go to Q2 · In-house designer for one company → **X** · Developer only, no design → **X** · Other → **X** |
| 2 | (Agency only) How many people work at your agency/studio? | 2–10 → T small agency · 11+ → **X** (outside both quotas) |
| 3 | In the last 12 months, how many websites have you built **for clients**? | 0 → **X** · 1 → hold (only if quotas unfilled) · 2+ → Q |
| 4 | When did you last finish or launch a client website? | Within 6 months → Q · 6–12 months → hold · Over 12 months → **X** (memory too old) |
| 5 | What did you use to build the last one? (open) | Any tool → record (for the mix). Hand-coded only, no visual tool, ever → hold |
| 6 | On that project, who did the design and build work? | Mostly me → supports solo tag · Me + teammates → supports agency tag. If answer contradicts Q1, use this answer for the quota and note it |
| 7 | How did the client give feedback before launch? (open) | Any answer → Q. "Client never saw it before launch" → hold, note for H3/H4 |
| 8 | After launch, who changes the site (text, images, pages)? | Any answer → Q, record (H3 "change" step) |
| 9 | Do you work for a website-builder company, or are you building one? | Yes → **X** |
| 10 | Can you do a 45-min recorded video call in [language: English / Urdu]? | No to call → **X** · No to recording → OK, notes only |

**Quotas:** 3 solo, 2 small agency. Prefer ≥1 current Buildrick user, ≥1 maintains sites after launch. Stop recruiting a tag when full.
**Hold** = accept only if the quota can't be filled otherwise; note why.
