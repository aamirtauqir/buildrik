| No selection / special object | Page appearance / Theme-toggle / AI / loading/error/role body | Preserve meaningful special contexts instead of forcing ordinary four-tab content |

## Shared control contracts

### IC-01 — Identity and navigation

| Contract field | Required behavior |
|---|---|
| Canonical owner | Editor session and selection; document names/IDs are separate authored data |
| Values, units and defaults | Stable page/object/resource IDs; active tab; section/open state; field focus; scroll; breakpoint/state; canvas pan/zoom; pending draft. No navigation control writes a property. |
| Availability and scope | Preserve existing destination/role access; exact target must still exist. |
| Interaction and state | Header stays above tabs. Same-task picker/resource return restores pinned context. Deliberate new page/selection supersedes stale return intent. Scope change settles valid edits against original target and preserves/reverts invalid draft explicitly. |
| Validation and errors | If target is deleted or permission revoked: “This item is no longer available”; return to valid source/page without assigning elsewhere. |
| Commit, reset, persistence and recovery | Navigation has no document Undo; Rename is a separate authored command with Enter/Escape. Tab/scroll preferences are temporary state, migrated without touching content. |
| Keyboard and focus | Tabs use tablist semantics and arrow navigation; Enter/Space activates actions; innermost Escape closes overlay; return focus to invoker; property search reveals exact field. |
| Multi-selection | Header uses N selected; ancestor navigation and inspect-one are deliberate selection operations. |
| Acceptance | Same-page resource round trip and intentional page switch preserve the right context without stale restoration. |

## Compatibility and dependency contract

- **UI-state migration only for relocation:** retain old Style/Behaviour/Effects tab preferences at their matching destinations; initialize Content deliberately. Map section/search aliases to new fields. Store per-object/tab scroll separately from authored content. No page IDs, element IDs or resource IDs change because of regrouping.
- **One authoritative property:** alternative status links/search/context doors reach the same operation. Choice Submission value is a facade over the existing nested input value; it must not add a wrapper value. Classes mean membership unless a verified definition-editing route is opened. Column count uses actual children and gap uses actual styles.
- **Lossless compatibility before shipping:** nested Select options, inline SVG, compound CSS expressions, component overrides, custom attrs, advanced grid tracks and old widget structure require fixtures. Read compatibility covers existing saved values; any serialization/API/schema change needs an explicit migration plan outside this annex.
- **Two recovery owners remain separate:** document history handles scoped element edits; asset upload, form delivery settings, CMS records and component definitions use their actual owner recovery. A design cannot promise a universal Ctrl-Z where the service does not support it.
- **Permissions unchanged:** this annex cannot grant Viewer Inspector access, definition management, shared token edit, upload, recipient edit or new commerce authoring. Apply current rights in engine/service and recheck late callbacks; a disabled row alone is insufficient.
- **Deferred rows preserve available work:** current disclosures substitute for retired density mode; generic product elements remain; existing CMS binding/device visibility remains; custom saved CSS remains. Revisit conditions are explicit in each Defer row. No deferred optional interface licenses deleting its stored data.
