## Capture contract

For every reconstructed state, record family ID, state name, route/fixture, role, actual viewport, device/breakpoint, canvas zoom, selection, host shape, entry control and capture date. Attach a screenshot **and** DOM/native layer evidence where available. Record which controls scroll, loading/error/save status, active surface, nested overlay and return-focus target. Mask tokens, credentials and personal content.

Use observed 1440×900 as a convenient desktop reference and retain the known 1280×720 failure reference; neither is an approved new layout dimension. A screen captured at one size is not proof of responsive behavior. Development Agentation controls should be identified as tooling, not reconstructed as product chrome.

FullPageRouter currently mounts Templates, expanded Assets, Settings and Brand in full-screen portals. CMS replaces the canvas/inspector region while rail and drawer remain. CompareHost uses a transient overlay. Publish/Review/History/Activity replace the inspector column. AI and Issues are separate right-column modes. These distinctions are load-bearing AS-IS facts; do not normalize all of them into one proposed panel type. See [FullPageRouter](../../src/editor/sidebar/FullPageRouter.tsx), [StudioPanels](../../src/editor/shell/StudioPanels.tsx), [RightColumnPanel](../../src/editor/shell/RightColumnPanel.tsx) and [tab registry](../../src/editor/rail/tabsConfig.ts). Runtime controls win over stale registry comments.

**Must capture** below means missing or insufficient current visual evidence for a reconstruction claim. It is not an instruction to mutate remote data, invoke a provider, or reproduce a dangerous defect. If the necessary genuine state is unavailable, retain a labelled source-only or historical-reference slot. A family can contain several representative screens; these 40 families are not a claim that exactly 40 frames exhaust the product.

## Suggested capture sequence for the root browser owner

These are navigation groups, not new routes added to the application. The authenticated editor URL is `/edit/[siteId]`; most editor destinations are stateful panels/workspaces, not independent browser paths. The Vite demo at `127.0.0.1:5050` must retain its separate provenance.

1. **Base shell and editing context — AS-01–08, 11.** Capture current no-selection and heading/image selection, Layers, the four menu hosts, View/breakpoint and multi-selection. Existing PNGs are a reference; no resize or native drag failure needs to be rerun to draw the settled screens.
2. **Creation and reusable content — AS-09–14.** Open Add, Components, Pages, Page settings and Templates. Prefer the existing populated component/page fixture. Open subordinate forms then cancel; do not apply templates or create components solely for completeness.
3. **Assets and CMS — AS-15–20.** Capture local asset chooser, manager and detail with truthful failed-sync status, then existing collection, draft record, field list and dynamic-page/settings screens. These have strong nonvisual runtime evidence but incomplete current screenshots.
4. **Brand and Settings — AS-21–28.** Capture every distinct subpage named in those families, using existing data. A grouped family does not excuse omitting a page. Capture workspace doors as doors; avoid navigating into billing/provider mutation flows. Record actual plan/role restrictions.
5. **Inspection and task modes — AS-29–37.** Open AI, Preview, read-only Publish, Review, History/Compare, Issues, Activity, Notifications and palette. The observed error/empty states are legitimate primary AS-IS states. Obtain missing populated states only from existing accessible data.
6. **Conditional boundaries — AS-38–40.** Capture genuine recovery/permission/export/share states if safely reachable. Share preview is source-confirmed to create a token on open when no reusable one exists; do not activate it without an established reusable authorized fixture. Leave external review, token, role and provider-dependent branches labelled unavailable when no appropriate fixture exists.

Highest-value fresh captures are **AS-10, AS-15–22, AS-29, AS-31–36**: components, populated CMS/media, bound Brand token, AI scope, Publish read state, Review error, History variants, Issues, Activity and Notifications. Existing test/JSON evidence cannot supply their editable visual hierarchy.

## What must not be silently treated as captured

- Native drag before/inside/after/cancel: attempted runtime coverage remained incomplete. Neither `native-after-drag.json` nor a source implementation is proof of a successful gesture or drop-feedback state.
- Successful remote media registration, cross-device assets and durable retry: registration500/local fallback was observed; the image recovery problem remains RT-01.
- Review delivery, client approval, publication, deployment rollback, provider OAuth, billing and domain changes: not performed in this audit. A designed confirmation or mock success board does not verify any of them.
- Viewer/admin differences, revocation, permission dialogs, session expiry and concurrency conflicts: source/contract coverage exists, but actual role/event fixtures are incomplete. Do not change application flags or DOM attributes to pass simulated presentation off as a real role.
- Complete interaction playback or exported/published parity: Preview uses a script-disabled iframe and responsive mismatch remains open.
- Multilingual publishing, planned export formats and other unsupported operations: their visible placeholders/disabled states belong in AS-IS; functional-success variants do not.
