Date: 2026-10-10. Scope: only the 14 assigned current-state frames on page `8280:2` in the existing Buildrick file. This pass made no application, browser, test, production data, earlier-frame, or TO-BE changes. Root supplied runtime captures and authorized the Figma corrections.

All 14 states were directly compared at 1440×900 against their saved browser PNGs, then all 14 corrected native Figma renders were inspected. Every frame retains its original ID, parent page, and 1440×900 bounds. This is a bounded visual reconstruction result, not pixel identity or functional certification. Root owns the overall Phase 4 gate.

## Corrected reconstruction errors

- Removed false native ellipsis from text that the browser actually shows in full. CSS `text-overflow: ellipsis` alone does not prove visible truncation: the capture often reports a tight DOM Range width, while Figma reserves more glyph space. The patch processed 382 labels; two actual truncations were restored after comparison. True page-tab, short component row, narrow readout and token-label truncation remains.
- Restored six mixed inline paragraphs (86, 90–93, 99). The DOM Range union starts at the second line's left edge and overlaps the preceding inline run when flattened. The original sentence is now one editable text node with browser-observed line breaks; superseded inline nodes remain hidden for traceability.
- Restored four original JPEG master previews using the source data URI supplied by root, at observed 254×11.28125 display dimensions inside the original 256×100 preview slots. The tiny clipped-looking Heading in this source thumbnail is preserved.
- Restored six original audit PNG image fills in the three asset tiles of each chooser (95/96). Only content thumbnails use raster fills; the surrounding interface remains native editable nodes.
- Added the Scope select's source SVG chevron in 86. Corrected the mobile canvas's rounded white surface and scaled shadow in 97. In 98, restored the measured page-wrapper clipping, including the bottom boundary and rounded left corners; the template remains horizontally clipped exactly as the captured app state.
- Preserved 98's observed centered, clipped breadcrumbs rather than replacing that current application flaw with a normal ellipsis. Restored native bold Arimo button fallbacks and used Noto Emoji for two otherwise missing template glyphs in 99; these remain explicitly approximate.

- Inter browser/native glyph metrics, baseline positioning and a few multiline wraps differ slightly. Some genuine ellipsis stops one or two characters earlier/later. CSS select value clipping differs slightly in the CMS collection field.
- Focus-ring/outline details, native checkbox ticks, selected canvas border/shadow composition and the transformed green spacing diamond remain approximate. The source focused Name field in 86 has an additional outer ring beyond the native border/shadow reconstruction.
- Browser Times/Arial template fonts are represented with Tinos/Arimo. The two lower template emoji in 99 use native monochrome Noto Emoji, visibly unlike the browser color glyphs. Noto Color Emoji was available to load but rendered invisibly; the monochrome fallback is named in the affected nodes and recorded honestly.
- The source master preview and all three media assets are the real supplied audit images, not invented content. Empty/broken canvas image state remains as captured. Developer Next.js issue chrome is excluded; the captured Agentation feedback circle remains where the v2 input included it and is not a product capability.
- Form 94's PNG was captured during `Saving…`, while its computed layout recorded `Unsaved changes`. The Figma frame follows the layout snapshot and the report preserves the timing discrepancy.
- 98's source filename remains `template-confirm` for traceability, but it is **Empty page replacement applied**. Root attempted Undo afterward; later Layers evidence still showed Navigation and two Sections, so restoration was **not verified**. The disposable audit draft retains the applied template. 99 is the separate nonempty Home guard with backup checked; root observed Cancel. No successful backup, replacement, Undo, CMS bind, component detach, or deployed interaction behavior is inferred from these static frames.
