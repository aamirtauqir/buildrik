## Recommended bounded operation model

One eligible Video Embed, three ratios, explicitly identified stock base legacy styles, independently scoped existing Desktop/Mobile styles, and a visibly recoverable valid/invalid URL fixture suffice. Show **“Video ratio · This video · all breakpoints.”** Reuse the existing chooser behind the eligible canonical Style row; Settings becomes a route. Preserve existing Style entry initialization, caller return/persistence and other family guards.

Represent raw ratio presence and value separately from effective ratio. Store the exact legacy pair/presence in a ratio-operation snapshot. Missing, present-empty, malformed and explicit `16:9` must not be silently merged if offered as recoverable states. If only absent and the three valid values are modeled, declare imported empty/malformed raw restoration outside the fixture.

Recommended Reset policy: remove the raw ratio attribute and resolve to default `16:9`; also remove the explicitly identified stock base legacy pair when present, with the same cleanup disclosure as a ratio choice. This closes the earlier plan's unspecified Reset-plus-legacy case. Reset never recreates obsolete sizing. It is a proposed R44 policy, not existing application behavior. Undo alone restores the pre-operation raw attribute and migrated declarations. If migration-on-Reset is not authored, label that case OPEN rather than claim complete reset recovery.

A normal same-effective-ratio click without migration is a no-op and retains useful Undo. A same-ratio click that removes known legacy sizing is a real edit. Malformed-value normalization is a separate explicit operation or an unrepresented gap; it must not be simultaneously claimed as no-op and normalization. Reset on explicit `16:9` is a real raw-storage change; Reset on already-absent ratio without migration is a no-op.

Ratio snapshots should restore only the ratio and the legacy declarations that operation owned. URL, flags and unrelated style edits must survive ratio Undo. If the finite implementation snapshots a wider tuple instead, every intervening writer to that tuple must advance a checked revision or invalidate that snapshot with explanation. A navigation/device switch must not invalidate useful Undo, restore the old device, or write a stale player height: derive geometry from the current device plus restored ratio.

## Bounded acceptance matrix

Each mutation below checks unchanged URL, provider identity, playback flags, classes, unrelated base styles and Mobile styles unless that row explicitly edits them. “Undo” means the finite one-step recovery, not engine history certification.

| Case | Setup/action | Required result and recovery |
|---|---|---|
| Canonical ownership | Enter Ratio through Settings and ordinary Style on both devices | Same eligible control/chooser and current value; all-breakpoints copy; no second independent editor, CSS/class binding or Mobile override indicator. Other families do not inherit the Video row. |
| Three-ratio output | Exercise all nine ordered source→target combinations on Desktop and Mobile | Six changed pairs update the designated player box; three same-value pairs are no-ops without migration. At actual player width W, heights are W×9/16, W×3/4 and W. Ratio text and geometry agree. Record actual post-authoring widths, not historical website width. |
| Scope | Change global ratio on Mobile; switch Desktop; edit independent Mobile style; switch back | Same ratio on both devices; unrelated Mobile style remains its own override. Ratio choice/reset/Undo never copies or deletes responsive style state. |
| Absent versus explicit | Start absent; choose default; separately start explicit `16:9`; Reset | Recommended absent/default selection stays absent/no-op. Explicit default Reset removes presence and is undoable back to explicit default. No generic “inherit from Desktop” copy. |
| Reset non-default | Explicit `4:3` and `1:1`; Reset; repeat Reset; Undo | First Reset removes attribute/defaults to `16:9`; repeat preserves first Reset's snapshot; Undo restores exact prior explicit value. |
| Legacy change | Known stock base pair; choose every ratio from either device | Remove only base height/padding pair in the same modeled operation; disclose replacement; preserve overflow/position/radius/background and all Mobile/pseudo declarations. Undo restores pair and raw ratio exactly. |
| Legacy same ratio | Effective `16:9` with known legacy pair; choose `16:9` | Genuine migration despite unchanged displayed ratio; Undo restores pair. Do not allow equality guard to skip the migration. |
| Legacy Reset | Known base pair with absent or explicit ratio; Reset | Under recommended policy, migrate pair and remove attribute together; Undo restores exact pre-reset pair/presence/value. No-op only when both ratio absence and no migration already hold. |
| Authored lookalike | Non-stock authored percent/zero styles, responsive pair or unresolved provenance | Preserve styles or explicitly refuse unsupported migration; do not apply the source's broad regex as proof of stock origin. General CSS interactions remain OPEN. |
| Navigation/no-op | Valid edit; repeat ratio; chooser Cancel/Escape; close/reopen Style; switch device; Undo | No navigation/no-op consumes the useful snapshot. Undo affects current target's owned state and derives output for the current device. Chooser cancellation is no-write; it does not undo a previously committed immediate choice. |
| Target and stale guard | Open route/chooser, then change target identity, type, membership, revision or selection cardinality | Choice, Reset and Undo revalidate the captured eligible target; refuse without writing a replacement target. Message preserves return context. Revision guards include every field a snapshot may overwrite. |
| Protection | Lock/read-only/conflict before choice, Reset or Undo; toggle protection after an edit | All write paths refuse consistently. If the finite model clears Undo on protection changes, disclose it and ensure unlock cannot revive the old snapshot. Separate policy approximation from source own-lock filtering. |
| Mixed/incompatible | Two videos with different ratios; video plus another type; partially locked set | Explicit unsupported single-video-only state and no write is sufficient for finite acceptance. A primary ratio display plus partial writes is not mixed-selection acceptance. |
| Invalid and missing URL | Invalid/missing source, then route/change ratio/Reset/Undo | Retain exact URL and visible error/recovery surface, including after legacy removal. Do not show successful provider/player status or repair URL implicitly. An empty URL may use empty-state copy rather than the source's invalid-link note. |
| URL recovery isolation | Invalid source → choose ratio → recover valid sample URL | Valid specimen uses chosen ratio. URL recovery is a separate operation; subsequent ratio Undo must not silently restore the invalid URL. If wide snapshot recovery is invalidated, explain that boundary. |
| Flag isolation | Toggle autoplay, muted or controls before/after a ratio action | Ratio choice/reset/Undo preserves current unrelated flags. Source defaults versus explicit off/bare-on remain distinct when represented. Player-loading/autoplay-policy claims remain excluded. |
| Unsupported raw ratio | Imported empty/malformed value resolving to default | Clear fallback status; either explicit normalization with raw-state Undo or declared unsupported fixture. Reset can remove it if represented; never claim custom ratio support. |
| Layout/return | Tall `1:1` on both devices; return to Settings and reopen | Correct player ratio with reachable error/Undo/return controls. Distinguish expected viewport scroll from clipped content. Retain target/device/caller; shared Style close persistence still works. |

Recommended browser minimum: Mobile Settings Ratio → canonical Style → `4:3` output → Desktop same global ratio → repeat choice and cancel/reopen → Reset → Undo → known legacy migration/Undo → invalid-source recovery surface → Settings return/reopen. Interpreter coverage should include guard/no-op/raw-presence cases and preservation of unrelated values; native geometry/reference checks are separate evidence.
