# R46 — General Size, Layout and layout-item contract plan

14 October 2026. Read-only source/register audit for R40 queue item 5. Only this plan was written. No Figma discovery or mutations, application/test changes, browser playback, register or main handoff edits. Tests below were inspected, not run. All 14 module gates remain OPEN.

**Scope is the complete general sizing/layout family:** dimensions and limits; container Flex/Grid arrangement; child sizing/placement; Position/offsets; overflow/box sizing; precise property origin and recovery. The ordered tasks below make that scope executable. Completing one fixture or Width mode does not close the other tasks. R39 Icon sizes, R40 Columns count/Gap, R44 global Video Ratio and R45 bounded Heading/Image visibility remain separate evidence. R45 browser/report work is still in progress at this checkpoint; its passing live-action checks do not certify general layout geometry.

## State and recovery model required across every task

Store target ID + generation, parent ID + layout context, active breakpoint/pseudo state, and **raw presence/string/revision per property and scope**. Derived mode, effective value, measured geometry and origin are separate. Absence, `0`, `0px`, Auto, `none`, `100%`, `fit-content`, token refs and equal-looking inherited values remain distinct. A row must say whether a visible number is authored, resolved or measured.

One operation captures only the property set it owns. Single Width Undo cannot restore old Height, Gap, parent Display, typography, asset or visibility. An alignment-grid action owns two declarations; both require exact presence/value recovery and a shared no-partial-restore guard. A newer edit to either owned declaration refuses stale Undo or uses real history conflict resolution; unrelated changes survive. Changing device/navigation never consumes the snapshot. Capture scope before opening a draft/chooser; changing target, generation, scope or parent mode must not redirect a pending write silently.

Default finite same-mode/same-explicit-value choices and absent Reset are no-ops that preserve useful Undo. If a user intentionally pins an inherited value or replaces a token/custom expression with a literal, it is a real change despite identical output; give that action its own explicit contract. Cancellation must restore raw pre-edit state if the prototype previews live values. Do not use an entire target snapshot for convenience.

## Ordered finite acceptance tasks

Use an identified parent and at least three distinguishable children: a wrapping text child, a solid fixed-size child, and an image child. Reuse family roots/controls after native discovery; add real child selection/Layers entries only where absent. Keep document child IDs/order/content unchanged unless the task explicitly concerns document structure—which this family does not.

1. **Width/Height modes and exact raw recovery.** Enter the named child via canvas and Layers; show its parent and current device. With a documented 600px usable parent content width and zero-padding/border specimen, Fill gives a 600px child; Fixed-from-measurement stores 600px; shrinking the parent to 360px changes Fill but leaves Fixed 600px (overflow is visible/explained). A short text specimen demonstrates Hug, then longer wrapping text changes its content-driven size. Test width and height separately; height Fill requires a definite containing height or an explanation. Repeat on a padded/bordered content-box specimen to expose measurement conversion, and on border-box. Same mode, untouched readout, Cancel, Reset and Undo preserve raw presence and unrelated axis. Return/reopen retains identity and origin. A fixture-only 200px fallback is never described as measured output.

2. **Units, limits and token origins.** Change a fixed width through finite px/%/rem/vw/vh choices with explicit parent/viewport/root-font reference dimensions. Show that switching 50px→50% changes physical width, rather than claiming automatic conversion. Exercise valid zero, invalid negative dimension, empty removal, allowed keyword, unsupported draft and corrected entry. Set min/max on both axes; resizing the parent and wrapping content must visibly reach the limit, not just change its label. A contradictory min/max pair needs a clear outcome or no-write validation. Reset only one limit; Undo restores its raw value/presence. Bind a valid size token, leave field untouched, edit token resolution, unlink to the actual current value, Undo binding; unresolved-token recovery preserves the reference. Page Max width is a separate single-row variant to cover, not an inferred pass from element Width.

3. **Container Display, Flex axes, alignment and gaps.** From generic Container, choose Flex and reveal only relevant controls; from Flex/Stack roots reach the same property contract without duplicate ownership. Switch Row/Column and reverse while three named children visibly reposition, preserving document order. Toggle wrap at a narrow content width; demonstrate nowrap overflow versus wrapping and wrap-reverse. In a 600px inner row with three 100px children and 24px gaps, two gaps consume 48px and the remaining 252px makes distribution measurable. Exercise main/cross-axis alignment, stretch/baseline and multi-line align-content with nonidentical child heights. The 3×3 grid is one two-property operation. Edit row/column gap independently; reset one longhand reveals any shorthand rather than resetting both. Same choices, cancellation and exact Undo retain child sizes/content. Block/None keep Display reachable; Grid switches eligibility while retaining inactive Flex declarations for recovery.

4. **Flex item behavior and responsive parent changes.** Select child B by exact Layer/ID, not its container. With a 600px inner parent, two 100px fixed children, 24px gaps, and B basis100/grow1, B receives the remaining 352px in the deliberately simple fixture (no min constraints, margins or competing grow factors). Change grow ratios, shrink under insufficient space, basis versus Width, min-width constraints, align-self versus parent align-items, and signed order. Rendered order may change; Layers/document order must not. Parent Row→Column changes the main axis; Flex→Block hides irrelevant item controls without deleting their raw values. Seed Tablet parent Flex with no Mobile override and verify Mobile item eligibility inherits it. Capture a pending child edit, then change/reparent/delete/protect the parent: explain/refuse stale context. Child Undo preserves a later unrelated parent property change when eligibility remains valid.

5. **Grid tracks and child placement.** Choose Grid on the same container; 600px inner width, gap24 and three equal tracks gives 184px per track; a two-track spanning child is 392px including the internal gap. Change 3→2 tracks without deleting children; explicitly author rows/auto-flow and show which child moves. Select a child, set column and row spans, full row, align-self/justify-self; retain custom imported placement as Custom until deliberately replaced. Exercise custom track string→count with a consequence preview or explicit replacement label→Cancel→commit→exact raw Undo. Invalid 0/25/noninteger count is no-write and recoverable; empty removes the template. Include auto-fit/auto-fill and dense-flow as separately labelled remaining leaves until they have meaningful output, not a misleading numeric count. Track/placement Undo must preserve other child content and parent declaration changes outside its owned property set.

6. **Position, offsets, stacking and overflow.** Select a child; Static→Relative visibly shifts it while preserving its flow slot. Absolute explicitly identifies its containing parent and removes that slot; set parent positioning deliberately rather than silently editing it. Offset `0px`, negative offset, Auto and absence have separate recovery. Exercise competing opposite offsets with explicit/auto dimensions and explain resulting size. Fixed and Sticky require a scrollable specimen and observable viewport/scroll-parent behavior, not a mode label. Demonstrate z-index with overlapping named siblings and known stacking context. Overflow Visible/Hidden/Auto/Scroll and X/Y must alter clipping or reachable content; box-sizing visibly changes outer geometry under padding/border. CSS visibility retains the slot and Layers recovery; Display None/device flags remove it. Float/Clear retain their own illustrative flow task. Each row resets only itself and can Undo without erasing size or positioning declarations.

7. **Cross-device origin and eligibility/protection matrix.** For one representative property in each family, author base→Tablet→Mobile with explicit local presence, inherited equal value, local Reset, Undo and return; test a Tablet override that must affect Mobile. Include pseudo-state and component/master origins as demonstrated leaves or explicit outstanding tasks, never fake them with a generic “Mobile override” badge. Cover inline/nonreplaced sizing, inline-block, replaced image intrinsic size, out-of-flow child eligibility, absent parent, mixed parents, mixed values, partial locks, protected instances/ancestors, conflict pending, deleted/replaced target and same-ID generation change. Explain refusals without writes; preserve draft and recovery. A conservative single-target prototype refusal is a design decision, not source multi-selection parity.

8. **Integration and complete evidence reconciliation.** Reopen from canvas/child Layers after resizing, wrapping, clipping and hidden states; selected identity, device, origin and parent context must remain correct. Retest R45 visibility/Display access, R38 typography, Image source/fit, R39 Icon sizing, R40 Columns Gap and R44 Video Ratio only at shared controls touched by this pass. New authoring must not leak flags/controls across other callers or overwrite their state on Close/Back/Escape. Map every inspected advanced/item property to an existing or newly justified row; preserve existing IDs and document new recovery controls inside their property contracts. Finite choices must be labelled; arbitrary dimensions, content or CSS are not accepted by a two-value fixture.

The arithmetic fixtures above are proposed acceptance setups, not current Figma measurements. Record actual content box, padding, border, margins, constraints and rounding before comparing screenshots. A numeric badge or reaction destination cannot substitute for visible child bounds, wrapping, clipping, scrolling and reflow.

## Evidence required and remaining implementation work

Each task needs an initiating route/selected identity; property owner and units; raw/effective/origin state; visible outcome; same/no-op; error/cancel; exact scoped Reset/Undo; protected/missing/stale outcome; and return/reopen. Use three independent evidence layers: (1) read-only live-action interpretation with a geometry/cascade oracle and no native state writes; (2) native instance/destination/binding/current-layout inspection; (3) browser captures that actually show target geometry and recovery. Passing permutations are repeated assertions, not accepted-task counts or a completion percentage.

Source component tests in `sections/__tests__/SizeSection.test.tsx`, `sections/layout/__tests__/{LayoutSection,FlexControls,GridControls,ItemControls,PositionControls}.test.tsx` and `shared/controls/__tests__/InputWithUnit*.test.tsx` cover useful callbacks/mode parsing/mixed labels and mocked measurements. They were not rerun here and do not establish actual engine atomic Undo, complete CSS layout, persistence, arbitrary inputs or native focus behavior.

Implementation gates remain separate: full responsive/pseudo/class/token cascade; property-specific validation; measurement/box-model agreement; exact parent/item eligibility; transaction batching and rollback; partial locked selection policy; engine Undo/Redo; real DOM layout/intrinsic media/percentage-height behavior; keyboard/focus/announcements; arbitrary track/expression/token import; canvas/export and durable save/reload agreement. Designable invalid/recovery and ownership states remain design work even while those runtime gates are pending. This plan closes no Size, Layout, Inspector or global module gate.
