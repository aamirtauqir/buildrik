Lesson 03 · One component system

Ratchet

Pichle lesson mein ek line thi: ratchet 402 → 0. Wahi wajah thi ke 29,179 lines ek commit mein delete ho sakin. Ye lesson batata hai wo cheez hai kya — aur aap ise abhi apne repo par chala kar dekh sakte hain.

Ek line ka matlab

agar (ab > baseline) → exit 1 → build fail

Bas itna. Pana (wrench) ka ratchet ek taraf ghoomta hai, doosri taraf lock ho jata hai. Code ka ratchet wahi hai: jo number aap kam kar rahe hain wo gir sakta hai, barh nahi sakta. Barha, to build ruk gayi.

Ye kyun ahem hai Aap ek aisi migration kar rahe hain jo hafton chalegi. Beech mein aap koi feature banayenge, koi bug fix karenge — aur ek inline style wapas add kar denge, bina jane. Ratchet ke bagair migration khamoshi se ulti chalti rehti hai aur kisi ko pata nahi chalta.

Aap ka ratchet abhi kya kehta hai

$ node scripts/check-styling-ratchet.mjs

[styling-ratchet] ok   inline_literal  1280 (baseline 1280)
[styling-ratchet] ok   inline_hoisted   590 (baseline 590)
[styling-ratchet] ok   css_lines      10940 (baseline 10940)
[styling-ratchet] PASS — one-component-system drain holding

Uski yaaddasht ek JSON file hai — scripts/.styling-baseline.json:

{
  "inline_literal": 1280,
  "inline_hoisted": 590,
  "css_lines": 10940,
  "css_files": { "inspector/styles/inspector.css": 1038, … }
}

Ab dekhein wo rokta kaise hai

Maine abhi ek inline style add ki — bilkul wo cheez jo aap hata rahe hain:

<div className={WRAP} style={{ padding: 99 }}>

Aur ratchet chalaya:

[styling-ratchet] FAIL inline_literal  1281 > baseline 1280 (+1)
[styling-ratchet] ok   inline_hoisted   590 (baseline 590)
[styling-ratchet] ok   css_lines      10940 (baseline 10940)

New inline styles or CSS lines were added to editor chrome.
Target is a chrome-ui component styled with `tw:` utilities.

EXIT CODE = 1

Ek inline style. Poori build ruk gayi. Ye koi warning nahi jo log mein guzar jaye — verify:ds ka hissa hai, aur wo push se pehle chalta hai.

Do commands, aur ek khatra

CommandKaam
check-styling-ratchet.mjsCheck kare. Barha to exit 1.
--topSab se bhaari files bataye — agla target chunne ke liye.
--updateNaye numbers baseline bana de.
Ratchet isi tarah marta hai --update wo cheez bhi hai jo ratchet ko bekaar kar deti hai. Red build ko green karne ke liye chalayenge, to aap ne kuch drain nahi kiya — aap ne goalpost hila diya aur ceremony rakh li. Qaeda: --update sirf number girane ke liye, aur usi commit mein jo batata ho kya drain hua.

Sirf total ginna kaafi nahi

Ye asli output hai, is session ka:

[styling-ratchet] ok   css_lines  10939 (baseline 10940, drained 1)
[styling-ratchet] FAIL shell/chrome.css grew 45 -> 50 (+5)

Ek panel mein 5 lines add, doosre se 6 minus. Total −1 — yani aggregate kehta hai "drained". Par architecture ulti chali. Isi liye baseline mein css_files map hai jo har file alag lock karta hai.

Aur ye kaise pata chala Code padh kar nahi. Violation plant karke. Gate ko fail hote hue dekha gaya — teen tarah se — tab bharosa kiya gaya. Ek gate jise aap ne kabhi fail hote nahi dekha, wo gate nahi, ek dua hai.

Aap ne ek panel convert kiya. Ratchet kehta hai FAIL inline_hoisted 591 > baseline 590 (+1). Aap ko yaqeen hai aap ne styles hataye hain. Kya karein?

Bilkul yahi is session mein hua. Maine style={fontStyle} pass kiya aur comment likha "token ki apni face — genuinely computed". Wo galat tha: `{fontWeight: 800}` aur `{fontStyle: "italic"}`, har button ka static literal. Ratchet +1 par fail hua aur sirf isi wajah se maine dobara padha. Pehle teen options us +1 ko dafan kar dete.

Yehi wo cheez hai jo aap ne maangi

Aap ne kaha "sara code clean hona chahiye". Clean kaha nahi ja sakta — napa ja sakta hai. Aap ke teen number:
