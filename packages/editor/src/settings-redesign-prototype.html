Workspace

Overview

The old Settings home was just a launcher. This redesign turns it into an operating dashboard: what is healthy, what blocks publish, what requires trust work, and where the user should go next.

Setup health

  • Missing favicon
    Site panel should show this as a required trust surface, not an optional detail.
  • Domain not verified
    Publish should inherit the same status and not pretend the site is fully ready.
  • Meta defaults incomplete
    SEO should expose global defaults plus page-level handoff.

Quick actions

  • Verify custom domain
    Jump to Domain & Publish with DNS instructions already visible.
  • Open Publish workflow
    Use the same connected domain, not a separate hidden state.
  • Resolve consent warning
    Go straight to Analytics & Consent and show publish consequences.
