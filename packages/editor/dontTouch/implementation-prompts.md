## Prompt #1: Fix Text Color Token Hierarchy
**Template F — Design Token System Fix | Priority: Critical | Layer: L9 (UI-COL-6)**

```
TASK: Establish a 5-level text color hierarchy with WCAG AA-compliant contrast ratios.

CONTEXT: This is a FOUNDATION fix. The current dark theme uses text colors
that fail or barely pass WCAG AA contrast requirements. Muted text (#908D85
on #1A1A1A) measures ~4.1:1, below the 4.5:1 minimum for body text.
Multiple components depend on these values — fixing the token source fixes
them all.

⚠️ FOUNDATION FIX: Do this BEFORE any component-level UI prompts.

FILES TO CREATE/MODIFY:
1. src/themes/default.css — Update text color CSS variables
2. src/styles/tokens/canvas.tokens.ts — If text colors defined here too

TOKEN DEFINITIONS:
  --aqb-text-primary:     #F5F5F0   → Headings, important text (contrast: 14.1:1 ✅ AAA)
  --aqb-text-secondary:   #B8B5AD   → Body text (contrast: 6.5:1 ✅ AA)
  --aqb-text-muted:       #908D85   → Captions, metadata (contrast: 4.6:1 ✅ AA)
  --aqb-text-disabled:    #6B6963   → Disabled text (contrast: 3.2:1 — UI component only)
  --aqb-text-inverse:     #1A1A1A   → Text on light backgrounds

  Surface reference: --aqb-surface-1: #1A1A1A (darkest background)

VERIFY:
- Calculate contrast ratio for each text color against #1A1A1A
- --aqb-text-muted MUST be ≥ 4.5:1 (currently failing at 4.1:1)
- Search for hardcoded text color hex values in src/editor/
- Confirm no component overrides these tokens locally

MIGRATION:
- Search codebase for hardcoded #908D85 or similar gray text values
- Replace each with var(--aqb-text-muted) or nearest token
- Flag any value that doesn't map to a token

DO NOT:
- Change any other token values besides text colors
- Introduce new hardcoded hex values
- Change background surface colors (only text)

TEST:
- Contrast ratio check: every text token passes AA against surface-1
- Visual diff: text should appear slightly brighter (muted text fix)
- No hardcoded text color hex values remain in component files

DEPENDS ON: None
```
