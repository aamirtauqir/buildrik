## A.1 — TOP BAR (Topbar.tsx)

```
┌─ TOP BAR (48px height) ─────────────────────────────────────────────────────────────────────────┐
│ [PROJECT NAME ✏] [↩Undo] [↪Redo]  │  [📱][💻][🖥️][⬜ Wide] DeviceSwitcher  │  [👁 Preview] [🚀 Publish] │
│       LEFT CLUSTER                 │         CENTER CLUSTER                  │    RIGHT CLUSTER          │
└─────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**Source:** `src/editor/shell/Topbar.tsx`

### Left Cluster
| Control | Behavior | State |
|---------|----------|-------|
| Project name (editable) | Click → inline edit; saves to composer | Shows placeholder when empty |
| Undo button | `composer.history.undo()` | Disabled when stack empty |
| Redo button | `composer.history.redo()` | Disabled when nothing to redo |

### Center Cluster — DeviceSwitcher (DeviceSwitcherPill)
| Segment | Breakpoint |
|---------|------------|
| Mobile (📱) | ~375px |
| Tablet (💻) | ~768px |
| Desktop (🖥️) | ~1280px |
| Wide (⬜) | ~1440px |

Active segment highlighted. Canvas re-renders at selected breakpoint. Changing device fires `onDeviceChange` callback up to `AquibraStudio`.

### Right Cluster
| Control | Behavior |
|---------|----------|
| Preview button | Opens preview mode (full-screen iframe or modal) |
| Publish button | Triggers `onPublish` callback → opens Publish sidebar tab or fires host-side deploy |

### Deprecated Props Still in API (DEAD CODE IN INTERFACE)
From `Topbar.tsx` — documented inline as `@deprecated`:
- `zoom` — zoom now lives in canvas footer
- `onShowTemplates` — templates accessed via rail tab
- `onShowAI` — AI accessed via canvas context menu
- `onOpenHistory` — history is a sidebar tab
- `onOpenSettings` — settings is a sidebar tab

**Observation:** These deprecated props pollute the public API and imply the topbar previously housed more functionality that was relocated. They create confusion for integrators.

### Missing States
- No **saving indicator** (auto-save spinner/checkmark) anywhere in the UI
- No **connection status** indicator (online/offline/cloud sync) — only `SyncStatusIndicator` exists in `src/editor/sync/` but wiring to topbar is unclear
- No **project-level breadcrumb** — can't navigate back to dashboard from editor

### CRITICAL GAP: 4 Tabs Have No Rail Buttons

| tabId | Label | Shortcut | Access Method |
|-------|-------|----------|---------------|
| templates | Templates | T | Keyboard shortcut ONLY |
| components | Components | ⇧A | Keyboard shortcut ONLY |
| publish | Publish | U | Keyboard shortcut ONLY |
| history | History | H | Keyboard shortcut ONLY |

**Impact:** Users who don't know keyboard shortcuts cannot discover Templates, Components, Publish, or History panels. These are critical features — especially **Publish** — that should be visually discoverable.

### Rail State: Active Tab Behavior
- Active tab: indigo `#7c6dfa` fill + 3px left indicator bar
- Clicking an already-active tab toggles the drawer (collapse/expand)
- Keyboard: ArrowUp/ArrowDown navigates between tabs; Home/End to first/last
- Tooltips: CSS-driven (no JS state), appear on hover with keyboard shortcut

### Rail State: Drawer Interaction
- `drawerOpen` prop controls whether the 280px sidebar drawer is visible
- Active tab + `drawerOpen=false` = both tab and drawer appear inactive

### Missing States
- No **notification badge** (badge API exists in code as `warn/info/ok` types but unused)
- No **active rail state when drawer is closed** — tab appears deselected even though it's "last opened"
