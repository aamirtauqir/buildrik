Core rules

  • 1One accent — cobalt #2D6DFF. CTAs, links, active states, focus rings. Purple/violet/indigo banned.
  • 2Red = error/danger only. Never a red CTA or hover. (info = the cobalt accent, not a second blue.)
  • 3Tabular data in Geist Mono + tabular-nums — counts, currency, sizes, seats, dates via MetricValue. Hero stat metrics may use the display font (Inter Tight), as the artifact does; consistency within a surface beats mono everywhere.
  • 4No default font stacks. Inter Tight + Geist Mono only — no system-ui / Arial / Roboto, no named fallbacks.
  • 5Cards earn their existence. No decorative card grids, no 3-col icon-in-circle features, no colored left-border cards.
  • 6No emoji as design elements. Use lucide icons.
  • 7Prefer named text tokens — but artifact-matched pixel values (text-[13.5px], font-[520]) are allowed when matching a mockup 1:1. Depth via hairline borders + subtle shadow, not heavy elevation.
